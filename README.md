# VTomRadio-BT-MaSo

Bluetooth module firmware/code for the eRadio VTomRadio project based on ESP32.

---

### ⚠️ Work in Progress (Development / Experimental)
This project is currently in the **initial development phase** and under active tuning. **It is not intended for final deployment or production use yet.** Features and communication protocols may change without prior notice.

---

## 📡 Hardware & Communication

The ESP32 Bluetooth module communicates with the main VTomRadio unit via **UART** using plain text commands.

- **Interface:** UART
- **Protocol Format:** Plain text commands (Request / Response structure)
- **Primary Function:** Acts as a Bluetooth audio / data interface for the VTomRadio system.
